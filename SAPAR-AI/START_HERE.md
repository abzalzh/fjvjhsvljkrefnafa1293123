# Абзал: что делать сейчас

Ты можешь начать первым: в этом пакете уже есть backend и предложенные общие схемы. Остальным не нужно угадывать формат запросов и ответов.

1. Распакуй весь `SAPAR-AI`, запусти по README. Открой `/docs`, включи деморежим и проверь пример генерации.
2. Утром передай команде **весь архив**, чтобы версии схем совпали. Не отправляй только отдельный `main.py`.
3. Самиру дай `docs/handoffs/SAMIR.md`; Ерасылу — `docs/handoffs/YERASYL.md`. Там готовые инструкции для их нейросетей. Сообщения никому автоматически не отправлялись.
4. Вместе подтвердите предложенный контракт v1.0. Если схемы нужно менять, сначала измените Pydantic и тесты, затем выполните `scripts/export_contract.py` и разошлите обновлённый пакет.
5. Когда Самир создаст общий репозиторий, перенеси свои `backend/`, `scripts/`, `docs/`, `integration/` в `feat/backend`. Корневые README и `.gitignore` объединяйте вручную. Пустые `data/*.json` НЕ должны затереть реальные данные Ерасыла.
6. После получения данных запусти валидатор и тесты, отключи demo, проверь запрос на 70 000 KZT/3 дня/1 человека. Если реального маршрута нет, выясните, каких подтверждённых данных не хватает; не подгоняйте цены.
7. Подключи провайдер AI по инструкции Ерасыла, укажи origin frontend в CORS, затем размещай backend по `docs/deployment.md`.

**Готово:** сервер, расчёты, проверка ограничений, база, тесты, API, схемы данных, TypeScript-клиент, контракты и инструкции.

**Не готово без команды:** реальные 15–20 объектов, реальные транспортные шаблоны, Groq, frontend, совместная проверка и публичная ссылка. Это первая техническая поставка твоей части, а не заявление о готовности всего MVP.

## Короткое сообщение команде

> Подготовил backend SAPAR AI и предложенный контракт v1.0. В архиве есть OpenAPI, TypeScript-клиент, JSON Schema и отдельные инструкции для ваших нейросетей. Самир: начни с docs/handoffs/SAMIR.md. Ерасыл: с docs/handoffs/YERASYL.md. Демо использует явно синтетические данные; production-датасет пока пустой. Сначала подтвердим схемы, затем работаем каждый в своей зоне. Прошу не менять поля API самостоятельно.
