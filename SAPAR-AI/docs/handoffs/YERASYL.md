# Ерасыл — инструкция для твоей нейросети

Передай нейросети весь пакет SAPAR-AI, общее ТЗ и этот запрос:

> Я Ерасыл, отвечаю за AI и данные SAPAR AI. Абзал подготовил backend и предложенный контракт v1.0. Сначала прочитай docs/data-contract.md, docs/dataset.schema.json, docs/api-contract.md, backend/app/schemas/contracts.py и backend/app/services/ai_gateway.py. Моя зона: реальные data/*.json, backend/app/services/ai/, backend/tests/ai/ и research/. Не переписывай планировщик, API, shared Pydantic-схемы и gateway без согласования. Начни с одного проверенного маршрута и всех зависимостей, прогони scripts/validate_data.py; затем расширяй датасет до 15–20 объектов. Все цены, координаты, часы, расписания, инфраструктуру и сезонность проверяй по реальным источникам и указывай даты проверки. Синтетические fixtures — пример структуры, не источник туристических сведений. Изучи ограничение дневного возврата в базовый город; не записывай ночёвки в горах в виде возврата в Алматы. Неизвестные поля оставляй unknown/null. Для AI реализуй асинхронный Groq-провайдер по интерфейсу ниже, с валидированными частичными изменениями параметров и объяснениями только по рассчитанным данным. Добавь семантические и отказоустойчивые тесты по общему ТЗ. Отдельно дай Абзалу необходимые зависимости и инструкцию подключения.

## Интерфейс провайдера

```python
class GroqProvider:
    async def parse(self, text: str, preferences: dict) -> dict:
        # Return ONLY changed TripPreferences fields, e.g. {"travelers": 3}.
        # Never return {"changes": {...}} and never invent budget calculations.
        ...

    async def explain(self, trip: dict, language: str) -> str:
        # Ground explanation in this computed TripOption; no external prices.
        ...
```

Методы обязаны использовать асинхронный I/O и реагировать на отмену. Gateway ограничивает вызов 8 секундами по умолчанию; провайдер должен задавать сетевой timeout не больше этого значения. Ошибки можно выбрасывать: gateway даст fallback. Рекомендуется создавать клиент при старте приложения, закрывать при остановке; если нужен lifespan, согласуй его с Абзалом. Не создавай соединение с Groq на этапе импорта Python-модуля.

Подключение выполняет Абзал через `create_app(ai_provider=provider)`. До этого endpoints уже доступны и возвращают fallback. Ключ берётся из окружения, не попадает в JSON, логи и Git.

Обязательные проверки parser: не меняет неупомянутые параметры, сохраняет неоднозначность без догадок, не исполняет prompt injection, не генерирует неизвестные поля, не нарушает типы/лимиты, поддерживает RU/KK/EN. Валидация gateway отсекает неверные поля и значения, но семантику пользовательской просьбы должен проверять твой модуль.

## Разделение работы

В этом пакете нет `services/ai/`: папка свободна для твоего модуля. `ai_gateway.py` — точка интеграции backend, её не нужно заменять своим router. Не добавляй вторые endpoints с теми же путями. Скрипт `scripts/validate_data.py` уже проверяет общий контракт; дополнительные проверки качества источников можно добавить отдельно.

Вместе с результатом передай Абзалу четыре файла данных, список зависимостей, название класса/фабрики провайдера, инструкцию жизненного цикла клиента и результаты своих тестов. Если схема не подходит реальным данным, сначала предложи конкретное изменение, а не добавляй незнакомые поля.
